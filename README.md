# AI-Driven Ensemble Machine Learning Framework for Multi-Class Autoimmune Disease Classification

An advanced computational pipeline leveraging gut microbiome profiles and multi-model gradient boosting ensembles to perform non-invasive multi-class classification across 11 phenotypic classes (including 10 distinct autoimmune conditions and healthy controls).

---

## 📌 Project Overview

Disturbances in the gut microbiota (dysbiosis) are closely linked to host immune dysregulation and autoimmune disease pathogenesis. Traditional diagnostic approaches often focus on single-disease comparisons. This project introduces a unified framework utilizing genus-level microbial abundance profiles (423 genera) across 1,955 samples to accurately predict and differentiate between multiple autoimmune disorders simultaneously.

### Key Highlights
* **Dataset Scope:** 1,955 samples across 11 phenotypic classes (CD, CeD, HC, MG, MS, PS, RA, SLE, SpA, T1D, UC).
* **Feature Matrix:** 423 gut microbial genera abundance profiles.
* **Core Framework:** Comparative evaluation of XGBoost, LightGBM, CatBoost, and a Soft Voting Ensemble.
* **Biomarker Identification:** Feature importance analysis identifying key microbial taxa driving disease discrimination.
